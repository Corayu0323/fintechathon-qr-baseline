# 因子 spec 草案

研究说明版本：draft-0.2｜因子集版本：`factor_v0.2`｜日期：2026-09-25｜状态：8 个首轮因子已计算；公式模块拆分及旧矩阵逐年核验通过。

机器可读的因子定义以 [`factor_set_v0.2.json`](factor_set_v0.2.json) 为准；公式实现按 `formula_id` 注册在 `scripts/factors/formulas/`。因子集版本与单个公式版本分开管理：本因子集中每个公式当前为 `0.1`。修改公式时升级对应公式版本及因子集版本，并写入新的独立输出目录，不覆盖旧矩阵。

采用用户提供的“项目—约定”表格，并补充窗口长度、缺失处理及拟合依赖。这些是候选特征定义，不是已被证实有效的 alpha。数量与窗口都可修改；初版不机械扩展所有窗口组合。

共同规则见《研究流程spec草案.md》。这里的 \(t-j\) 是题给共同交易日历向前 j 个位置。OHLC 使用题给后复权价格，\(V\) 为 vol，\(A\) 为 amount。所有候选都是单股票、无标签依赖、无需估计参数的确定性因子；输出 float32，未应用 scaler。正负方向不预设为有效信号。

## 1. 通用表格模板

| 项目 | 约定 |
|---|---|
| 因子名称 / 列名 / 版本 | 填写 |
| 描述目的 | 描述什么状态；可检验的预测假设单独写，不当作事实 |
| 输入字段与口径 | 填写复权、量额单位等 |
| 数据窗口 | 明确起止交易日及是否包括当日 |
| 最晚使用数据 | 精确到字段及日期 |
| 信息可用时间 | 填写 |
| 最早可能交易时间 | 下一交易日存在可成交机会时；不是成交保证 |
| 因子定义 | 数学公式，含统计量分母和窗口端点 |
| 连续有效日线数 | `required_valid_bars`，避免回看跨度与点数混淆 |
| 缺失与特殊值 | 缺口、分母为 0、异常值处理 |
| 截面依赖 | 无，或明确当日范围、排名及并列处理 |
| 拟合参数依赖 | 无，或明确只在训练期估计的参数 |
| 输出 | 类型、自然范围（如有），是否未经 scaler |

## 2. 候选 R1 / R5 / R20：历史收益

这三个候选共享公式，但每个列名单独占一个 catalog 条目。

| 项目 | 约定 |
|---|---|
| 列名 / 公式版本 | `feature_ret_1d`、`feature_ret_5d`、`feature_ret_20d` / 各公式 v0.1；所属因子集 `factor_v0.2` |
| 描述目的 | 描述短期涨跌和较长回看涨跌；反转或趋势方向留待开发期检验 |
| 输入字段 | 后复权 close |
| 数据窗口 | \(t-h\) 至 \(t\)，\(h\in\{1,5,20\}\)，包含当日 |
| 最晚使用数据 | \(C_{i,t}\) |
| 信息可用时间 | \(t\) 日收盘、当日日线可用后 |
| 最早可能交易时间 | \(t+1\) 日存在可成交机会时 |
| 因子定义 | \(C_{i,t}/C_{i,t-h}-1\) |
| 连续有效日线数 | 分别 2、6、21；虽然公式只用端点，本版要求窗口不跨无效日线 |
| 缺失与特殊值 | 历史不足或窗口出现无效日线则缺失；非正分母报告数据异常 |
| 截面 / 拟合依赖 | 均无 |
| 输出 | 无量纲收益比率，未经 scaler |

## 3. 候选 B：当日收开盘变化

| 项目 | 约定 |
|---|---|
| 列名 / 公式版本 | `feature_intraday_return` / v0.1；所属因子集 `factor_v0.2` |
| 描述目的 | 描述当天开盘到收盘的价格变化 |
| 输入字段 | 后复权 open、close，要求同日复权尺度一致 |
| 数据窗口 | 仅 \(t\) |
| 最晚使用数据 | \(C_{i,t}\) |
| 信息可用时间 | \(t\) 日收盘、当日日线可用后 |
| 最早可能交易时间 | \(t+1\) 日存在可成交机会时 |
| 因子定义 | \(C_{i,t}/O_{i,t}-1\) |
| 连续有效日线数 | 1 |
| 缺失与特殊值 | 当前日线无效则缺失；open 非正报告异常 |
| 截面 / 拟合依赖 | 均无 |
| 输出 | 无量纲，未经 scaler；不包含前收盘到当日开盘的跳空 |

## 4. 候选 A：当日高低区间幅度

| 项目 | 约定 |
|---|---|
| 列名 / 公式版本 | `feature_range_open` / v0.1；所属因子集 `factor_v0.2` |
| 描述目的 | 描述当日最高与最低价格间距相对开盘价的大小 |
| 输入字段 | 后复权 open、high、low |
| 数据窗口 | 仅 \(t\) |
| 最晚使用数据 | 当日最终 \(H_{i,t},L_{i,t}\) |
| 信息可用时间 | \(t\) 日收盘、当日日线可用后 |
| 最早可能交易时间 | \(t+1\) 日存在可成交机会时 |
| 因子定义 | \((H_{i,t}-L_{i,t})/O_{i,t}\) |
| 连续有效日线数 | 1 |
| 缺失与特殊值 | 当前日线无效则缺失；open 非正或 high < low 报告异常 |
| 截面 / 拟合依赖 | 均无 |
| 输出 | 非负无量纲值，未经 scaler；不用“以前收盘为分母的振幅”名称混称 |

## 5. 候选 P：收盘在日内区间的位置

| 项目 | 约定 |
|---|---|
| 列名 / 公式版本 | `feature_close_position` / v0.1；所属因子集 `factor_v0.2` |
| 描述目的 | 描述收盘更接近当日高点还是低点 |
| 输入字段 | 后复权 high、low、close |
| 数据窗口 | 仅 \(t\) |
| 最晚使用数据 | 当日最终 high、low、close |
| 信息可用时间 | \(t\) 日收盘、当日日线可用后 |
| 最早可能交易时间 | \(t+1\) 日存在可成交机会时 |
| 因子定义 | \(H_{i,t}>L_{i,t}\) 时为 \((C_{i,t}-L_{i,t})/(H_{i,t}-L_{i,t})\)；\(H=L=C\) 时定义为 0.5 |
| 连续有效日线数 | 1 |
| 缺失与特殊值 | 当前日线无效则缺失；H=L 但 C 不相等或 C 不在 [L,H] 则报告异常，不强行裁剪 |
| 截面 / 拟合依赖 | 均无 |
| 输出 | [0,1]，未经 scaler；平盘取中点是一项显式设计约定 |

## 6. 候选 V：成交量相对前五日均值

| 项目 | 约定 |
|---|---|
| 列名 / 公式版本 | `feature_volume_rel_5d` / v0.1；所属因子集 `factor_v0.2` |
| 描述目的 | 描述当日成交量相对近期的放大或缩小 |
| 输入字段 | 题给原始 vol，同一字段前后单位一致 |
| 数据窗口 | \(t-5\) 至 \(t\)；分子用当日，分母只用前五日 |
| 最晚使用数据 | \(V_{i,t}\) |
| 信息可用时间 | \(t\) 日收盘、当日日线可用后 |
| 最早可能交易时间 | \(t+1\) 日存在可成交机会时 |
| 因子定义 | \(V_{i,t}/[\frac{1}{5}\sum_{k=1}^{5}V_{i,t-k}]-1\) |
| 连续有效日线数 | 6 |
| 缺失与特殊值 | 窗口无效或分母为 0 则缺失；当日量为 0、分母为正时结果为 -1；负成交量报告异常 |
| 截面 / 拟合依赖 | 均无 |
| 输出 | 无量纲，正常非负成交量下至少 -1，未经 scaler |

不将该字段称为“换手率”，因为没有流通股本。原始成交量可能受股本变动影响，不能假定已与后复权价格具有相同复权口径。

## 8. 集合级约定与可修改项

首轮计算并使用以上 8 列，作为 fixed 基线的共同起始因子集，`min_valid_run=21`。因此即便某行具备单日因子，21 日历史不足时仍不进入这套模型的完整样本集合。相关性高本身不构成删除理由；后续在 D 中通过增删对照决定是否保留，若改用更短窗口清单则同步调整历史要求并报告覆盖率变化。

首版缺失/历史长度/涨跌停标记只作为辅助信息，不自动作为模型特征；若要进入模型，另列因子定义并做对照。后续新增波动、均线偏离、截面排名等因子时沿用模板，不直接默认接入整个 Alpha158。

首轮沿用上文公式：保留 20 日收益，量额均值排除当日，平盘位置取 0.5。因子诊断报告 IC/RankIC 及覆盖率；组合是否有用以相同评估协议下的模型官方综合分验证，不按单因子 IC 排名机械截取。每次改变公式、窗口或缺失约定都更新因子版本；不得沿用旧名字掩盖定义变化。
