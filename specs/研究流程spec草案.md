# 研究流程 spec 草案：外层评估与内层模型维护

版本：draft-0.5｜日期：2026-09-25｜状态：研究设计草案；fixed 的 D/H/S 基础流程已实现，rolling/adaptive 尚未实现。

保留 D／H／S 作为外层 evaluation framework，在其中比较 fixed／rolling／adaptive 三种 model-maintenance strategies。初始拟合区间不再意味着整个预测阶段禁止重训；具体更新权限由策略及标签时钟共同决定。详细维护规则见《模型维护策略spec草案.md》。Regime 识别、aging 判别与改善是可选扩展，不作为当前主线验收条件。

本稿同时作为代码的执行规格。旧版本保存在 `archive/`，不作为当前执行规范；代码只实现 fixed D/H/S，不代表维护策略研究系统已完成。

当前执行范围：D 完成真实因子、输入变换和基础模型的 fixed 比较；冻结 D 选择后，在 H 运行一次历史检验，并在 S 生成正式测试预测。每次 fixed 运行都在预测期内冻结模型。rolling/adaptive 留作后续研究，相关参数未定不阻塞首轮。不同开发实验可以重新训练，但不能据预测期反馈修改同一次 fixed 实验的模型。

## 1. 决策状态与术语

| 项目 | 本稿约定 | 状态 |
|---|---|---|
| 输入范围 | 仅题给日频量价和允许使用的标志字段 | 题给约束 |
| 标签 | 题给原始 `y_ret_1d`，不重算覆盖、不归一化用于评分 | 已有约定 |
| 外层评估 | D 开发、H 最终历史检验、S 正式预测 | 用户明确的分层设计 |
| 内层维护 | 首轮 fixed；后续在相同外层时期比较 rolling/adaptive | 首轮不启用维护 |
| scaler | 训练期估计的参数随模型版本冻结；可选每日横截面变换按第 7.4 节固定规则计算 | 区分训练期参数与当日截面统计 |
| 更新类型 | rolling/adaptive 设计批量重训；逐日独立更新训练期 scaler、partial_fit 和微调仍关闭 | 本轮设计范围 |
| 可选扩展 | regime 识别、aging 判别与改善 | 非必要，不阻塞主线 |
| 时间划分、scaler 种类、候选因子 | 本稿提供具体起点 | 待用户修改的研究选择 |

“训练集”在本稿中分为两种含义：`provided_train` 是题给 2018—2024 年有标签文件；`fit_period` 是某次实验真正允许用来拟合的时间段。两者不能混用。“整个训练期 fit scaler”仅指后者中的合格样本。

每个模型允许训练期内部的较早样本使用由该模型整个拟合期估计的 scaler，因为模型在该次训练结束后建立；训练内预测不构成当时的样本外预测。数据只有在相应信息时点之后才能进入后续版本的拟合，不能反过来改变已保存的历史预测。

外层评估控制研究者何时可修改方案；内层维护控制算法何时可修改模型参数。H 中冻结研究规则，rolling/adaptive 仍可按已登记策略利用此前成熟的标签自动更新。静态 scaler 不等于所有策略全阶段固定模型。

## 2. 信息时点与目标

设题给共同交易日历为 \(d_0,d_1,\ldots\)，记 \(t=d_k\)，\(t-j=d_{k-j}\)。全部日期差按交易日历解释，不按自然日计算，也不按某只股票的非空记录计数。

| 对象 | 约定 |
|---|---|
| 一条样本 | `(trade_date=t, ts_code=i)` |
| 当日原始记录 | \(O_{i,t},H_{i,t},L_{i,t},C_{i,t},V_{i,t},A_{i,t}\) 及题给标志 |
| 因子信息边界 | 最晚只能使用日期 \(t\) 的数据 |
| 日线可用时点 | 假设在 \(t\) 日收盘并完成日线汇总后；数据没有更细发布时刻 |
| 预测时点 | 当日日线可用后生成 \(\hat y_{i,t}\) |
| 预测目标 | \(y_{i,t}=C_{i,t+1}/C_{i,t}-1\)，评分用题给原值 |
| 标签成熟时点 | \(t+1\) 日收盘后，且题给标签非空 |
| 最早可能交易时点 | 下一交易日存在可成交机会时；不是成交保证 |
| 交易解释 | 该标签包含收盘至次日收盘的收益，不等于次日实际入场后的可实现收益 |

不把所有因子统一滞后一天。因子是否包含当日值由其公式决定，完整当日日线只用于收盘后的预测。禁止用下一条非空价格替代缺失的下一交易日价格。

`model_fit_asof`、`scaler_fit_asof` 和 `label_maturity_date` 必须记录。日期级截止默认解释为该日收盘并完成数据汇总后；标签成熟日小于等于拟合截止日才可训练。若改成盘前流程，需要另改截止语义。

## 3. 数据、单位与版本

| 项目 | 约定 |
|---|---|
| 原始文件 | 原样保留，记录 SHA256；派生步骤不覆盖原始文件 |
| 主键 | `(trade_date, ts_code)`，两者非空且联合唯一 |
| 行顺序 | 不依赖原文件偶然顺序；显式排序和按键连接，保留 `source_row` 追溯 |
| 价格 | 使用题给后复权 OHLC，不自行改复权方式 |
| 量、额 | 题目明确 vol 单位为股、amount 单位为元；单位明确不等于已确认二者与后复权价格的复权口径一致 |
| 口径混合 | 不构造 `close / (amount / vol)` 等未核对尺度的价格比值 |
| 数据快照 | 因子与实验记录引用同一源数据版本，不能实验中途静默换数据 |
| 因子数据类型 | 计算时可用 float64，落盘 float32；标签保持处理后原有精度 |
| 价格合理性 | 非正价格、非有限数、OHLC 关系异常作为数据错误报告，不静默修复 |

因子因果性检查是在题给固定数据快照上验证算法不读取未来行；单凭此快照不能证明供应方的历史复权值从未被事后修订。报告按题给数据口径描述。

## 4. 外层评估协议与内层策略的边界

| 外层阶段 | 初始拟合期 | 预测与维护模拟期 | 研究者权限 | 策略权限 |
|---|---|---|---|---|
| D：开发比较 | 2018—2020 | 2021—2023 | 比较因子、模型及维护规则，记录尝试 | fixed 不更新；rolling/adaptive 按各自规则使用已成熟数据 |
| H：最终历史检验 | 2021—2023 | 2024 | 事先冻结全部研究规则，禁止据结果人工调参 | 按交易日先后执行相同策略，允许预先登记的自动重训/替换 |
| S：正式测试预测 | 2022—2024 | 2025 至题给测试末日 | 应用预先选定方案，不回看测试未来调整规则 | 受是否允许使用测试期派生标签的权限限制 |

“预测与维护模拟期”指初始模型训练完成后，按交易日先后生成预测、等待真实收益实现，再按预定规则评估和维护模型的期间。每一步只能使用当时已知的信息。

表中的拟合期是各阶段的起点，不是 rolling/adaptive 整个运行期的唯一训练来源。同一阶段、同一基础模型的三种策略从相同初始模型/scaler 出发；阶段之间重新初始化模型和监测状态。因子历史可接续，旧模型的监测误差不能直接作为新模型的历史。

- D 的预测用于开发选择，因此即使每条预测都满足因果性，也不是未参与研究选择的独立检验。
- H 冻结的是因子、基础模型配方、策略参数、候选检验与评价规则。H 内已成熟标签可作为预定策略的反馈；不能人工看结果修改这些规则，也不能把尚未成熟的 H 标签提前释放。
- S 是否允许用测试期已实现收益训练尚未明确；当前保留 `provided_train_only` 的 fixed 提交分支，以及停用的 `causal_realized_test_labels` 分支。不能将前者当作“比赛要求只能拟合一次”，也不能声称后者已获允许。
- 2024 年已用于接口烟测并读取过少量标签，未据烟测效果选择正式因子或模型；保留该记录。
- D/H/S 的预测期限不同，各策略仅在相同日期区间内直接比较；跨阶段报告需注明期限和初始训练历史差异。

每次模型重训共用同一配方：最近约 36 个月历史，内部最后约 3 个月做验证。先只在内部 train fit scaler 和模型，用内部 valid 按预定规则选轮数；再在允许的 train+valid 中使用截至该次拟合时点成熟的标签重新 fit 配套 scaler 和模型。train 初次拟合、合并重训都各自遵守成熟边界。详细时钟、触发、未来影子检验和预算见《模型维护策略spec草案.md》。

上述内部验证与合并重训也用于首轮 fixed 的初始拟合，不代表预测期内维护；精确日期边界以维护 spec 第 4 节为准。首轮原始一日标签回归使用平方误差损失，Ridge 另含其 L2 正则项。LightGBM 内部 valid 以 MSE 选择训练轮数，再按既定流程合并重训；开发期最终模型选择使用第 10 节的官方综合分，不以训练损失或 valid MSE 代替。

fixed：阶段内不重训。rolling：按季度批量重训。adaptive：近期表现触发候选训练，未来影子检验通过后替换。三者使用相同因子、基础模型、数据版本、预测键与评分；adaptive 多了候选检验，初步比较评价整套策略，不把收益单独归因于触发时机。

## 5. 因子计算 spec

每个因子采用《因子spec草案.md》的表格形式。必填：名称、版本、公式、字段及单位、窗口是否包含当日、最晚输入、信息可用时间、最少连续有效日线数、缺失规则、截面依赖、是否估计参数、输出类型。

统一规则：

1. 时间序列运算按股票分组，按共同交易日历排序；保留缺口位置。不能先删缺失日再 rolling。
2. 当前默认不跨无效日线拼接窗口。因子窗口需要多少个日线位置，直接写成 `required_valid_bars`，避免“5 日回看”与“6 个价格点”混淆。
3. 确定性因果因子可在全时期预计算，训练边界不能清空历史；读训练期以前的 warm-up 数据仅用于因子，不扩大拟合样本范围。
4. 原始因子矩阵保留基础公式结果；其每日横截面标准化/排名作为第 7.4 节的可选输入变换，不重复计算原始因子。
5. 因子代码只接收白名单量价字段和所需标记，不接收 `y_ret_1d` 或其派生值。标签驱动筛选在建模模块执行，并遵守拟合/开发边界。
6. 数据版本和公式版本不变时，单批、分年、分股票批次计算应得到相同结果，允许预定浮点误差。
7. 全期估计的分位数、全期标准化、PCA 不属于可直接预计算的原始因子。

## 6. 缺失、可用性与监督样本

| 标记 | 定义及使用 |
|---|---|
| `bar_valid` | 当前 OHLCV/amount 全部非缺失，沿用已处理数据定义 |
| `volume_zero` | 当日观察到成交量为 0；它不自动意味着行情缺失 |
| `label_present` | 题给标签非缺失 |
| `label_available` | 标签非缺失且在当前拟合截止日已成熟 |
| `history_ready_L` | `valid_bar_run` 达到所选因子清单的最大 `required_valid_bars` |
| `model_ready` | `bar_valid & history_ready_L` 且所有已选因子为有限数 |
| 监督拟合样本 | `model_ready & label_available`，并位于指定拟合日期范围 |

首版使用完整因子样本，不启用 imputer。行情完整但标签缺失的行保留用于历史因子计算及预测，不进入监督损失。未来若启用训练期填补，需要单独修改本规则，不能暗中将缺失填 0。

当前严格历史要求作用于完整日线：即便某个价格因子只需要 close，也遵守已约定的连续有效日线规则。这是保守研究选择，若以后改为字段级历史可用性，需要版本变更和对照。

因子分母为 0 时输出缺失，不加极小常数制造极端值；恒定价格区间的收盘位置可按其因子 spec 特别定义为中点。不同因子的特殊规则不能静默共用。

## 7. 因子、训练标签与预测输出的预处理 spec

本节规定“处理什么、如何变换、输出代表什么”。拟合日期、内部 train/valid 划分、重训及版本冻结由第 4 节和《模型维护策略spec草案》第 4 节统一规定；本节不另设时间窗口或更新频率。以下是设计约定，不表示相关处理器已实现。

### 7.1 默认组合与处理顺序

| 处理对象 | 默认方法 | 输出含义与选择理由 |
|---|---|---|
| 原始因子表 | 保留第 5 节定义的收益率、量额比率、价格位置等，不原地修改 | 保留因子的数值含义；无量纲不等于各列尺度相同 |
| Ridge 的因子输入 | 默认 `train_zscore`，可切换第 7.4 节的输入变换 | 输入表示相对训练期均值的偏离，减少因子尺度对正则化的影响 |
| LightGBM 的因子输入 | 默认 `identity`，可切换第 7.4 节的输入变换 | 树切分通常无需统一均值和方差，默认直接使用原始因子值 |
| 一日训练标签 | 保留题给原始 `y_ret_1d` | 保留收益差距，作为解释明确的单任务基线 |
| 正式模型输出 | 一日收益预测，不额外排名、截尾或平滑 | 保留输出单位；单模型预测的每日严格递增变换本身不改善排序 |
| 评价标签 | 始终使用题给原始 `y_ret_1d` | 与训练目标变换隔离，所有方案按同一官方口径评价 |

执行顺序：读取原始因子和标签 → 按第 6 节确定样本资格 → 变换模型输入及训练目标 → 模型拟合/预测 → 必要的目标反变换 → 按第 9 节补齐预测 → 第 10 节评分。不得将预测回填值用于估计 scaler，也不得让 Qlib 默认处理器再重复变换一次。

### 7.2 训练期标准化（`train_zscore`）

令 \(\mathcal T\) 为第 4、6 节确定的本次合格拟合样本，\(n=|\mathcal T|\)。对每列因子 \(j\)，跨股票和日期合并计算：

\[
\mu_j=\frac{1}{n}\sum_{(i,t)\in\mathcal T}x_{i,t,j},\qquad
\sigma_j^2=\frac{1}{n}\sum_{(i,t)\in\mathcal T}(x_{i,t,j}-\mu_j)^2,
\qquad z_{i,t,j}=\frac{x_{i,t,j}-\mu_j}{s_j},
\]

其中 \(s_j=\sigma_j\)（\(\sigma_j>0\)），否则 \(s_j=1\)。本节只适用于 `train_zscore`；选择 `identity` 时跳过数值变换，但仍校验因子名、顺序和版本。

| 项目 | 必须满足的约定 |
|---|---|
| 统计轴与权重 | 每列一个中心和尺度；合格股票日样本等权，不按股票单独拟合，也不按每日横截面重新计算 |
| 精度 | 均值、尺度用 float64 计算并保存；方差采用 ddof=0；变换后的因子可转 float32 |
| 常数列 | 记录训练期常数列，尺度置 1；不据后续分布删除列 |
| 空样本与非有限值 | 无合格拟合样本、中心/尺度非有限，或合格行在变换后出现 NaN/Inf 时均报错，不静默填补或转成保守预测 |
| 新值超出历史范围 | 允许保留，不自动裁剪或调整已有统计量；若产生数值溢出则按上一行报错 |

### 7.3 训练标签的默认值与候选分支

训练目标单独生成，不覆盖原始标签。以下三个方案分开登记，首版只启用 A；B、C 是停用的研究候选，不默认叠加。

| 方案 | 训练目标及输出 | 启用边界 |
|---|---|---|
| A：原始一日收益（默认） | 直接拟合原始一日收益；预测无需反变换 | 不对标签标准化、截尾或排名 |
| B：每日横截面标准化标签（候选） | \(z_{i,t}=(y_{i,t}-\bar y_t)/s_t\)；模型输出表示相对表现分数 | 每日统计只用预先规定范围内、已成熟的合格标签；启用前明确股票范围、最少样本数和零方差处理。不能用未来真实 \(\bar y_t,s_t\) 还原预测收益；输出单位须注明为分数 |
| C：一日主任务＋五日辅助任务（候选） | 两个期限分别按训练期统计量标准化；正式只输出反变换后的一日预测 | 需要能让辅助任务影响主任务的共享学习机制；两个独立模型分别拟合不视为已实现辅助学习 |

方案 B 用来检验强调日内相对表现是否有益；它会改变不同日期的损失权重，不能称为纯粹的数值单位转换。所有候选仍用原始一日标签评价，不能以变换后损失或五日成绩替代官方结果。

方案 C 的尺度约定为：对每个期限 \(h\in\{1,5\}\)，在本次拟合范围内、因子合格且该期限标签已成熟的样本上，分别计算 \(\mu_h,s_h\)（ddof=0，float64）。定义

\[
z^{(h)}=\frac{y^{(h)}-\mu_h}{s_h},\qquad
\mathcal L=\operatorname{MSE}_{\mathcal T_1}(\hat z^{(1)},z^{(1)})
+\lambda\operatorname{MSE}_{\mathcal T_5}(\hat z^{(5)},z^{(5)}),
\qquad \hat y^{(1)}=\mu_1+s_1\hat z^{(1)}.
\]

其中 \(\mathcal T_h\) 是该期限的合格监督样本，每项损失按自己的有效样本数取平均。未成熟或缺失的五日标签只屏蔽辅助损失，不因此丢掉可用的一日监督。启用的任务无有效样本或标签尺度为零时，停止该次实验并报告，不静默改变任务。

五日标签定义为共同交易日历上的 \(C_{i,t+5}/C_{i,t}-1\)，最早在 \(t+5\) 收盘后可用；作为单独派生标签保存，不能作为当日因子输入。派生标签的数据权限沿用第 4 节。启用 C 前须补齐五日标签的缺失规则、可用性标记、模型结构及 \(\lambda\)，并扩展现有一日标签接口以支持各任务独立的监督掩码。

C 若选择 `train_zscore`，因子 scaler 仍以第 6 节的一日合格监督样本为统计集合；选择截面变换时使用第 7.4 节的无标签范围，均不因辅助标签缺失改变输入处理。其纯一日对照采用相同输入处理、相同一日标签缩放及主模型结构，仅设 \(\lambda=0\) 并关闭辅助任务；零权重任务不要求五日标签或其尺度可用。

### 7.4 可选输入变换

同一份原始因子矩阵通过 `input_transform` 选择一种变换，不串联叠加，不要求拼接三套特征或保存三份全量矩阵。三种变换与“不变换”选项如下；输入选择与第 7.3 节的标签选择独立。

| 配置值 | 处理方法 | 输出含义 |
|---|---|---|
| `train_zscore` | 按第 7.2 节用训练样本逐列估计均值/尺度 | 相对训练期通常水平的偏离；Ridge 默认 |
| `cs_zscore` | 每日、每列计算当日合格股票的均值和标准差，输出 \((x_{i,t,j}-\mu_{t,j})/s_{t,j}\) | 相对当天其他股票的数值偏离 |
| `cs_rank` | 每日、每列取升序平均名次 \(r_{i,t,j}\)，输出 \((r_{i,t,j}-1)/(N_t-1)-0.5\) | 当天相对排名，范围 \([-0.5,0.5]\)；并列值取平均名次 |
| `identity` | 不作数值变换 | 保留原始因子值；LightGBM 默认 |

两个 `cs_*` 选项共用以下规则：

- 当日范围为题给股票中该日 `model_ready=1` 的全部行，数量为 \(N_t\)；不按标签是否存在/成熟或涨跌停状态进一步过滤。先在这个范围计算变换，再按监督资格选取训练行。
- 每列统计只使用当日已知因子。`cs_zscore` 采用 ddof=0；当日常数列输出 0。\(N_t=1\) 时两种变换均输出 0 并记录；\(N_t=0\) 时不计算变换，由第 9 节处理预测覆盖问题。不合格行保持原缺失/资格标记，不因标准化变成合格行。
- 每次计算必须覆盖完整的当日合格范围，不能分别在不同股票批次或模型 minibatch 内排名/标准化。计算使用 float64，结果可保存为 float32；非有限统计量或结果报错。
- 变换方法随模型版本固定；每日统计量是按固定规则从当日因子计算，不是更新训练期 scaler，也不是在线学习。无需使用验证/测试标签，可按日期计算或缓存；缓存需绑定因子版本、股票范围和变换配置。

在 D 中固定其他设置比较输入变换；选定后用于 H 和维护策略比较。不因实现简单就默认增加因子数量或执行全部输入与标签的组合实验。

### 7.5 交付与验收

每个模型保存独立的输入变换状态和目标变换状态，二者不可混用。共同记录方法、列名与顺序、因子版本、输出单位及模型版本；训练期拟合的变换另存中心/尺度、统计样本数及键摘要、常数列和拟合时点；截面变换另存股票范围规则、并列/退化情况处理及当日样本数，绑定可复现的输入数据版本。恒等变换也显式登记。产物位置、原始表保护和全流程时间检查分别归第 8、11 节。

本节专属验收：

1. 手算小样本与实现结果一致，覆盖常数列、空拟合样本及非有限值。
2. 保存再加载变换状态后，相同输入得到相同输出；声明可逆的训练期标签变换能够反变换，容差按 float32/float64 明确记录。
3. 更换标签处理方案不修改原始标签；评分只读取原始标签。方案 B 不调用未来真实截面统计量反变换。
4. 如启用 C，分别检查一日/五日标签成熟边界、辅助损失掩码、零权重对照及最终只导出一日输出。
5. 如启用截面输入变换，验证完整日期计算与分批汇总计算一致，并覆盖并列值、常数列及单股票截面；改动标签不影响变换结果，新增未来日期不改变过去结果。

## 8. 存储与 Qlib 接口 spec

| 对象 | 存放/接口 | 契约 |
|---|---|---|
| 原始处理表 | `data/prepared/{train,test}_YYYY.parquet` | 保留原标签和辅助信息 |
| 原始因子表 | `data/features/<factor_set_version>/features_YYYY.parquet` | 主键和数值 `feature_*`，未做训练期拟合变换，保留全部源键 |
| 因子清单 | `specs/factor_set_v0.2.json`；构建时将分区清单写入版本目录内的 `catalog.json` | 列顺序、formula_id、公式版本、字段、窗口、缺失规则、因子集版本 |
| 窗口配置 | 由本文第 4 节转成配置 | fit/predict 范围、拟合截止、模式和更新开关 |
| 预处理产物 | 每次实验独立保存 scaler 状态 | 不写回原始因子表，不与其他实验共用可变状态 |
| Qlib 输入 | `(datetime, instrument)` 索引，feature/label 分组 | 按键转换、排序，标签与因子不得移位 |
| 评分输入 | 原始标签、预测、独立辅助标记 | 不能使用 Qlib 中按训练资格掩码后的标签 |

读取先限定年份、时间和列，再送入 Qlib；不复制全期原始数据生成 Qlib 默认市场库。未来真实因子落盘后测一次完整拟合窗口内存，并记录读取、变换、训练、预测各阶段；小样本内存不作为全量可行性证明。

缺失、重复、多余键，因子版本/顺序不匹配，拟合范围越界或 scaler 与模型不配套时，立即报错。

## 9. 预测与完整键输出 spec

`model_ready=1` 时由当日实际部署版本的配套 scaler 和模型生成分数；`model_ready=0` 时保留键和原因。若本来可预测的行产生 NaN/Inf，作为模型数值错误报错，不以保守回填静默掩盖。

对当日正常模型预测集合 \(P_t\)，无效行首版回填：

\[
p_{\mathrm{fallback},t}=\min(P_t)-\max\{\max(P_t)-\min(P_t),10^{-6}\}.
\]

它只是低优先级排序分数，不代表对未来收益的经济预测。若当日没有正常模型预测则停止。严格低于正常预测只保证排序靠后；要保证不会进入官方 Top 10%，还必须有足够多的非涨停正常预测填满官方要求的候选数量。每日检查该覆盖条件，不够则报出候选不足，不能宣称回填自动保证排除。

提交列为 `ts_code, trade_date, pred`，一键一行、覆盖全部题给测试键、pred 全部有限。内部另保留 model_ready、缺失原因、模型/scaler/因子版本。相同分数沿用官方排序语义，不为提高成绩事后添加随机扰动。

## 10. 评分与研究结论 spec

| 环节 | 指标或操作 | 用途 |
|---|---|---|
| 因子与选股能力诊断 | 日 IC（Pearson）和 RankIC（Spearman），以 RankIC 为主要排序诊断 | 使用已实现的一日收益，报告年份、有效股票范围和覆盖率；单因子诊断不直接决定最终模型 |
| 每日选股 | 对当时可得的模型预测分数排序，按官方规则形成 Top 10% | 当日真实收益尚未实现，不能拿当天 IC 直接选股票 |
| 开发期模型/输入/标签方案选择 | 官方综合分为主，三个分项及分年结果同时报告 | 在同一 D 预测区间和完整评价键上比较；不以 RankIC 单项替代综合分 |
| 后续维护 | RankIC 可用于退化监测，候选选择及整套策略评价使用官方综合分 | 首轮停用；细则见维护 spec，触发与选模型的指标分工不同 |

在预先登记的有限候选中，以完整 D 区间官方综合分最高者作为首选，不对分年分数另行平均后代替官方全期结果。分项、分年和成本用于说明优劣及局限；若分数差在评分数值容差内（绝对差不超过 `1e-12`），依次选择训练总耗时更低、峰值内存更低、登记顺序更早的候选。这里的数值并列只处理计算精度，不表示统计等效。H 前冻结选定方案；H 报告检验结果，不回头调参或重新挑赢家。若实验有数据/实现错误，修复后重跑并保留记录，不把错误结果用于选型。

正式指标复制题给脚本：日 RankIC 均值占 40%，Top 10% 年化超额收益占 30%，\(1-\)平均 Jaccard 距离占 30%。三个分项的过滤条件不同，分别使用脚本原规则；不能套统一训练过滤掩码。

- RankIC：仅在该分项中按原脚本排除缺失标签，至少 30 条。
- Top 收益：排除涨停和缺失标签，至少 100 条；分组数量按原脚本取整。
- Jaccard：排除涨停，不因标签缺失额外删行，少于 100 条时重置前日集合。
- 使用完整原始评价键，因子缺失行不从评价面板直接删除。各基线采用相同的回填和评价范围。
- 分年指标与整体指标同时记录，不用少量表现好的日期代表整个 OOS。
- 零方差预测等造成指标未定义时，报告该事实，不随意改成 0；评分实现继续核对官方返回语义。
- 官方无标签测试期没有可核实标签时不计算或声称正式测试成绩；Jaccard 指标不称为实盘资金换手。

## 11. 验收 spec

以下是后续实现必须通过的检查，本稿不表示这些检查已全部实现。

| 检查 | 方法 | 通过标准 |
|---|---|---|
| 因子截断一致性 | 全数据计算与截到 T 后计算比较 | T 及以前有效位置、缺失掩码一致；数值满足约定容差 |
| 未来扰动 | 改变 T 后量价再计算 | T 及以前因子不变 |
| 标签隔离 | 修改/打乱标签 | 未依赖标签的原始因子不变 |
| 手算小例子 | 价格序列、缺口、零量、平盘、股票交界 | 与每个公式及缺失规则一致 |
| 分区接续 | 连续计算与分年/分批计算比较 | 分区边界因子及缺失掩码一致 |
| 训练截止 | 设置跨界标签 | 未成熟标签不能进入对应监督任务；训练期 scaler 采用约定的合格拟合样本；无标签依赖的截面输入变换遵守第 7.4 节 |
| scaler 隔离 | 对某一具体 fit 事件，改动其信息截止之后的数据 | 该次 scaler 和固定配置的模型训练结果不变；不要求后续已合法消费新数据的版本不变 |
| 版本冻结 | 同一部署版本前后比较参数摘要 | 模型与训练期变换参数不变；截面变换规则不变，每日统计可随输入变化；只有已登记维护事件可切换到新版本 |
| 预测与决策未来扰动 | 改变 T 后输入并重放完整策略 | T 及以前的预测、触发、接受/拒绝决定均不变 |
| 候选检验 | 检查训练、影子日期、标签成熟和替换时点 | 影子期位于候选训练截止之后；完整检验标签成熟后才决策，最早下一交易日生效 |
| 同日横截面例外 | 改同日其他股票数据 | 若启用截面因子，允许同日预测变化；不能要求股票完全隔离 |
| 键与评分 | 全键对齐、原标签核查、对照官方脚本 | 没有漏键/重复键，评分在数值容差内一致 |
| 资源 | 真因子完整窗口实测 | 记录峰值内存、耗时、线程和版本，无内存溢出 |

因子 float32 比较默认 `atol=1e-7, rtol=1e-6`，先分别比较缺失掩码；因子尺度特殊时在该因子 spec 明确调整。评分与官方脚本对照默认绝对容差 `1e-12`。

注意：不能要求改变同次训练期后半段后，该次 scaler 变换的训练期前半段仍不变；整个训练期参与估计是批量拟合的定义。检查必须绑定具体模型版本和拟合截止；rolling/adaptive 合法消费新数据后可以形成不同的新版本，但不能覆盖旧预测。
