# 研究流程 spec 草案：滚动窗口与窗口内固定 scaler

版本：draft-0.2｜日期：2026-09-24｜状态：供用户修改，未作为运行配置启用。

主流程采用用户原先提出的 train／valid／test rolling window：每个窗口批量拟合 scaler 和模型，在该窗口的预测块内冻结，到下一窗口重新拟合。逐日更新 scaler 和增量学习仅预留。这里只修改规范文档，不改变已有数据、代码行为和研究结果。

本次修订撤销 draft-0.1 中“2018—2020 拟合后连续预测 2021—2023”的主流程设定，并取消 D／H／S 简称。长期固定模型仅作为可选的退化检查。窗口长度、步长和是否合并 train+valid 重训仍是明确列出的可修改研究选择。

## 1. 决策状态与术语

| 项目 | 本稿约定 | 状态 |
|---|---|---|
| 输入范围 | 仅题给日频量价和允许使用的标志字段 | 题给约束 |
| 标签 | 题给原始 `y_ret_1d`，不重算覆盖、不归一化用于评分 | 已有约定 |
| 建模主模式 | train／valid／test 滚动；窗口边界批量重训，test 块内冻结 | 恢复用户原先的滚动训练方向 |
| scaler | 每次在允许的整个拟合区间内估计一次，配套模型使用期间冻结 | 保留用户选择的静态 scaler 口径 |
| 在线功能 | 逐日更新 scaler、逐日重训和增量更新均停用；不包含预定的季度批量重训 | 仅预留接口 |
| 时间划分、scaler 种类、候选因子 | 本稿提供具体起点 | 待用户修改的研究选择 |

“训练集”在本稿中分为两种含义：`provided_train` 是题给 2018—2024 年有标签文件；`fit_period` 是某次实验真正允许用来拟合的时间段。两者不能混用。“整个训练期 fit scaler”仅指后者中的合格样本。

窗口内固定 scaler 允许训练期内部的较早样本使用由整个训练期估计的 scaler，因为模型统一在该次训练结束后建立；这些训练内预测不构成当时的历史样本外预测。该次 valid/test 数据不得提前参与这个 scaler 的估计。

Walk-forward 是重复推进训练与预测时间边界的验证协议；本稿采用季度步长和批量重训。Online learning 通常指持续或增量更新模型。静态 scaler 不要求多年冻结模型；关闭逐日更新也不要求关闭季度滚动训练。

## 2. 信息时点与目标

设题给共同交易日历为 \(d_0,d_1,\ldots\)，记 \(t=d_k\)，\(t-j=d_{k-j}\)。全部日期差按交易日历解释，不按自然日计算，也不按某只股票的非空记录计数。

| 对象 | 约定 |
|---|---|
| 一条样本 | `(trade_date=t, ts_code=i)` |
| 当日原始记录 | \(O_{i,t},H_{i,t},L_{i,t},C_{i,t},V_{i,t},A_{i,t}\) 及题给标志 |
| 因子信息边界 | 最晚只能使用日期 \(t\) 的数据 |
| 日线可用时点 | 假设在 \(t\) 日收盘并完成日线汇总后；数据没有更细发布时刻 |
| 预测时点 | 当日日线可用后生成 \(\hat y_{i,t}\) |
| 预测目标 | \(y_{i,t}=C_{i,t+1}/C_{i,t}-1\)，评分用题给原值 |
| 标签成熟时点 | \(t+1\) 日收盘后，且题给标签非空 |
| 最早可能交易时点 | 下一交易日存在可成交机会时；不是成交保证 |
| 交易解释 | 该标签包含收盘至次日收盘的收益，不等于次日实际入场后的可实现收益 |

不把所有因子统一滞后一天。因子是否包含当日值由其公式决定，完整当日日线只用于收盘后的预测。禁止用下一条非空价格替代缺失的下一交易日价格。

`model_fit_asof`、`scaler_fit_asof` 和 `label_maturity_date` 必须记录。日期级截止默认解释为该日收盘并完成数据汇总后；标签成熟日小于等于拟合截止日才可训练。若改成盘前流程，需要另改截止语义。

## 3. 数据、单位与版本

| 项目 | 约定 |
|---|---|
| 原始文件 | 原样保留，记录 SHA256；派生步骤不覆盖原始文件 |
| 主键 | `(trade_date, ts_code)`，两者非空且联合唯一 |
| 行顺序 | 不依赖原文件偶然顺序；显式排序和按键连接，保留 `source_row` 追溯 |
| 价格 | 使用题给后复权 OHLC，不自行改复权方式 |
| 量、额 | 保持题给单位；绝对单位未确认前不声称得到每股成交价格 |
| 口径混合 | 不构造 `close / (amount / vol)` 等未核对尺度的价格比值 |
| 数据快照 | 因子与实验记录引用同一源数据版本，不能实验中途静默换数据 |
| 因子数据类型 | 计算时可用 float64，落盘 float32；标签保持处理后原有精度 |
| 价格合理性 | 非正价格、非有限数、OHLC 关系异常作为数据错误报告，不静默修复 |

因子因果性检查是在题给固定数据快照上验证算法不读取未来行；单凭此快照不能证明供应方的历史复权值从未被事后修订。报告按题给数据口径描述。

## 4. train／valid／test 滚动窗口提案

### 4.1 每个窗口的数据角色

默认 train 33 个月、valid 3 个月、test 3 个月，窗口每次向前推进 3 个月。train+valid 合计为原计划的约 36 个月候选历史。具体长度属于研究默认值，不是赛事规定。日期均取范围内题给实际交易日。

| 窗口示例 | train：拟合 scaler 和模型 | valid：选择参数或训练轮数 | test：固定模型向前预测并评分 |
|---|---|---|---|
| 1 | 2018-01-01 至 2020-09-30 | 2020-10-01 至 2020-12-31 | 2021-01-01 至 2021-03-31 |
| 2 | 2018-04-01 至 2020-12-31 | 2021-01-01 至 2021-03-31 | 2021-04-01 至 2021-06-30 |
| 3 | 2018-07-01 至 2021-03-31 | 2021-04-01 至 2021-06-30 | 2021-07-01 至 2021-09-30 |

一个窗口中的 test 在后续窗口可以成为 valid/train，只要当时标签已经成熟；过去已经保存的 OOS 预测不能用后来模型覆盖。test 块彼此不重叠，连续拼接，不重复计分。

### 4.2 一个窗口内的操作顺序

1. 在 train 结束时点，只用 train 范围内已成熟、且模型可用的样本 fit scaler 和模型。valid/test 仅 transform，不能用于这次 scaler 的拟合。
2. 用 valid 标签按预先定义的规则选参数或 early-stopping 轮数。valid 没有参与该模型的梯度拟合，但参与了模型选择，不能当独立 test 汇报。
3. 首版沿用原计划：在 test 开始前，以选定参数和轮数，在 train+valid 的合格样本上重新 fit 一套 scaler 和模型。若启用标签驱动的特征筛选，也按预定规则在相应拟合范围内重新执行。这个重训阶段不再声称 valid 是未参与拟合的数据。
4. 对接下来的整个 test 季度逐日计算因子、transform、预测；模型与 scaler 参数冻结。test 标签只用于该块评价，不用于该块内更新。
5. 下一季度边界重新执行以上流程，逐日增量更新保持关闭。

可以把第 3 步配置为不合并重训，直接用 train 拟合的模型预测 test；这是另一种合法协议，但所有对照必须使用同一设定，不能看 test 结果后任选。首版默认 `refit_train_valid=true`。Ridge 无需 early stopping 时，valid 仍可按预定规则选择有限的正则化参数。

两个拟合阶段都检查标签成熟：首次拟合截止为 train 末日收盘后，合并重训截止为 test 开始前最后一个交易日收盘后。末日标签若尚未实现，保留原值但不进入当次 scaler/监督拟合。首次被排除的 train 末日标签，在合并重训时已经成熟则可以纳入。

### 4.3 开发期和最终历史检验

- 2021—2023 年：开发期，拼接这些年份的滚动 test 预测来比较方案。若依据这些结果修改因子或规则，它们属于研究开发验证，不能因窗口内名为 test 就称整个时期未参与选择。
- 2024 年：冻结研究规则后执行同样的滚动协议。冻结的是因子定义、候选参数范围、valid 选型规则、重训周期与评价方法；模型和 scaler 可按预定季度边界使用此前已成熟标签重新拟合。不得看完 2024 年结果再人工调整方案而仍称其独立检验。
- 2024 年已用于接口烟测并读取过少量标签，未用烟测效果选正式因子或模型；保留记录，不声称该年标签从未被任何程序读取。
- 每个 test 块内，因子可使用此前和当日量价；保持滚动因子历史不等于更新模型。

### 4.4 官方无标签测试期与可选固定模型对照

官方测试期的标签权限是另一项约束，不因历史验证采用滚动就自动改变。暂沿用原计划的离线提交口径：模型/scaler 在提供的历史训练标签上最终拟合一次，预测 2025 年至测试末日，不从测试价格自行生成标签重训。默认最终拟合期为 2022—2024 年，截止为 2024-12-31 收盘后；该日跨界标签仍按成熟规则排除。这是时点一致性选择，不冒称赛事禁止使用题给边界标签。

因此，历史季度滚动结果不能直接当成官方整个测试期冻结模型的表现证据。多年固定模型的优点在于检验长期不重训的退化，更接近上述提交方式；保留为可选诊断，当前不自动启动，也不替代主滚动协议。若以后需要据历史结果论证冻结提交方案，须补做相应期限的固定模型 OOS 检查。是否允许官方测试期按已实现收益重训，另行明确后再修改，不默认启用。

## 5. 因子计算 spec

每个因子采用《因子spec草案.md》的表格形式。必填：名称、版本、公式、字段及单位、窗口是否包含当日、最晚输入、信息可用时间、最少连续有效日线数、缺失规则、截面依赖、是否估计参数、输出类型。

统一规则：

1. 时间序列运算按股票分组，按共同交易日历排序；保留缺口位置。不能先删缺失日再 rolling。
2. 当前默认不跨无效日线拼接窗口。因子窗口需要多少个日线位置，直接写成 `required_valid_bars`，避免“5 日回看”与“6 个价格点”混淆。
3. 确定性因果因子可在全时期预计算，训练边界不能清空历史；读训练期以前的 warm-up 数据仅用于因子，不扩大拟合样本范围。
4. 允许当日截面运算，但需单列其当日股票范围、缺失规则和并列排名规则。首版候选暂不启用截面排名，以便先核对基础公式。
5. 因子代码只接收白名单量价字段和所需标记，不接收 `y_ret_1d` 或其派生值。标签驱动筛选在建模模块执行，并遵守拟合/开发边界。
6. 数据版本和公式版本不变时，单批、分年、分股票批次计算应得到相同结果，允许预定浮点误差。
7. 全期估计的分位数、全期标准化、PCA 不属于可直接预计算的原始因子。

## 6. 缺失、可用性与监督样本

| 标记 | 定义及使用 |
|---|---|
| `bar_valid` | 当前 OHLCV/amount 全部非缺失，沿用已处理数据定义 |
| `volume_zero` | 当日观察到成交量为 0；它不自动意味着行情缺失 |
| `label_present` | 题给标签非缺失 |
| `label_available` | 标签非缺失且在当前拟合截止日已成熟 |
| `history_ready_L` | `valid_bar_run` 达到所选因子清单的最大 `required_valid_bars` |
| `model_ready` | `bar_valid & history_ready_L` 且所有已选因子为有限数 |
| 监督拟合样本 | `model_ready & label_available`，并位于指定拟合日期范围 |

首版使用完整因子样本，不启用 imputer。行情完整但标签缺失的行保留用于历史因子计算及预测，不进入监督损失。未来若启用训练期填补，需要单独修改本规则，不能暗中将缺失填 0。

当前严格历史要求作用于完整日线：即便某个价格因子只需要 close，也遵守已约定的连续有效日线规则。这是保守研究选择，若以后改为字段级历史可用性，需要版本变更和对照。

因子分母为 0 时输出缺失，不加极小常数制造极端值；恒定价格区间的收盘位置可按其因子 spec 特别定义为中点。不同因子的特殊规则不能静默共用。

## 7. scaler 与其他预处理 spec

首版建议 Ridge 使用按列 StandardScaler，LightGBM 使用恒等变换。两者仍从同一原始因子矩阵、同一模型可用样本和同一时期开始；预处理差异写入实验记录。

设某次拟合的合格样本集合为 \(\mathcal T\)，对因子 \(j\)：

\[
\mu_j=\frac{1}{|\mathcal T|}\sum_{(i,t)\in\mathcal T}x_{i,t,j},\qquad
\sigma_j^2=\frac{1}{|\mathcal T|}\sum_{(i,t)\in\mathcal T}(x_{i,t,j}-\mu_j)^2.
\]

\[
z_{i,t,j}=(x_{i,t,j}-\mu_j)/s_j,\qquad
s_j=\begin{cases}\sigma_j,&\sigma_j>0,\\1,&\sigma_j=0.\end{cases}
\]

| 项目 | 约定 |
|---|---|
| 拟合样本 | 与该次监督拟合相同的合格训练行；跨股票合并按列估计，不按股票各 fit 一个 scaler |
| 权重 | 每个合格股票日样本等权，不额外做每日等权；记录实际行数 |
| 统计口径 | 方差 ddof=0；参数计算/保存 float64，变换后可输出 float32 |
| 常数列 | 训练标准差为 0 时尺度置 1，记录该列；不依据 OOS 分布删列 |
| valid/test 操作 | 对所属的固定模型仅 transform；下一窗口及明确的 train+valid 重训阶段重新 fit，不在 test 块内更新 |
| OOS 超出训练范围 | 允许超出；不据验证/测试范围重新缩放 |
| imputer / winsorization / PCA | 首版均关闭；将来启用时只在训练数据 fit 并版本化 |
| 标签处理 | 保持原始收益标签；首版不做标签标准化、截尾或横截面排名标签 |
| 状态保存 | 方法、特征名和顺序、均值/尺度、拟合区间与时点、样本键摘要、数据版本、scaler ID |

scaler 和模型作为配套版本使用。仅更新 scaler 会改变模型输入坐标，不能把它视为不影响模型的无害操作。

## 8. 存储与 Qlib 接口 spec

| 对象 | 存放/接口 | 契约 |
|---|---|---|
| 原始处理表 | `data/prepared/{train,test}_YYYY.parquet` | 保留原标签和辅助信息 |
| 原始因子表 | `data/features/features_YYYY.parquet` | 主键和数值 `feature_*`，未做训练期拟合变换，保留全部源键 |
| 因子清单 | 待确认后生成机器可读 catalog | 列顺序、公式版本、窗口、缺失规则、因子集版本 |
| 窗口配置 | 由本文第 4 节转成配置 | fit/predict 范围、拟合截止、模式和更新开关 |
| 预处理产物 | 每次实验独立保存 scaler 状态 | 不写回原始因子表，不与其他实验共用可变状态 |
| Qlib 输入 | `(datetime, instrument)` 索引，feature/label 分组 | 按键转换、排序，标签与因子不得移位 |
| 评分输入 | 原始标签、预测、独立辅助标记 | 不能使用 Qlib 中按训练资格掩码后的标签 |

读取先限定年份、时间和列，再送入 Qlib；不复制全期原始数据生成 Qlib 默认市场库。未来真实因子落盘后测一次完整拟合窗口内存，并记录读取、变换、训练、预测各阶段；小样本内存不作为全量可行性证明。

缺失、重复、多余键，因子版本/顺序不匹配，拟合范围越界或 scaler 与模型不配套时，立即报错。

## 9. 预测与完整键输出 spec

`model_ready=1` 时由固定的 scaler 和模型生成分数；`model_ready=0` 时保留键和原因。若本来可预测的行产生 NaN/Inf，作为模型数值错误报错，不以保守回填静默掩盖。

对当日正常模型预测集合 \(P_t\)，无效行首版回填：

\[
p_{\mathrm{fallback},t}=\min(P_t)-\max\{\max(P_t)-\min(P_t),10^{-6}\}.
\]

它只是低优先级排序分数，不代表对未来收益的经济预测。若当日没有正常模型预测则停止。严格低于正常预测只保证排序靠后；要保证不会进入官方 Top 10%，还必须有足够多的非涨停正常预测填满官方要求的候选数量。每日检查该覆盖条件，不够则报出候选不足，不能宣称回填自动保证排除。

提交列为 `ts_code, trade_date, pred`，一键一行、覆盖全部题给测试键、pred 全部有限。内部另保留 model_ready、缺失原因、模型/scaler/因子版本。相同分数沿用官方排序语义，不为提高成绩事后添加随机扰动。

## 10. 评分与研究结论 spec

正式指标复制题给脚本：日 RankIC 均值占 40%，Top 10% 年化超额收益占 30%，\(1-\)平均 Jaccard 距离占 30%。三个分项的过滤条件不同，分别使用脚本原规则；不能套统一训练过滤掩码。

- RankIC：仅在该分项中按原脚本排除缺失标签，至少 30 条。
- Top 收益：排除涨停和缺失标签，至少 100 条；分组数量按原脚本取整。
- Jaccard：排除涨停，不因标签缺失额外删行，少于 100 条时重置前日集合。
- 使用完整原始评价键，因子缺失行不从评价面板直接删除。各基线采用相同的回填和评价范围。
- 分年指标与整体指标同时记录，不用少量表现好的日期代表整个 OOS。
- 零方差预测等造成指标未定义时，报告该事实，不随意改成 0；评分实现继续核对官方返回语义。
- 官方无标签测试期没有可核实标签时不计算或声称正式测试成绩；Jaccard 指标不称为实盘资金换手。

## 11. 验收 spec

以下是后续实现必须通过的检查，本稿不表示这些检查已全部实现。

| 检查 | 方法 | 通过标准 |
|---|---|---|
| 因子截断一致性 | 全数据计算与截到 T 后计算比较 | T 及以前有效位置、缺失掩码一致；数值满足约定容差 |
| 未来扰动 | 改变 T 后量价再计算 | T 及以前因子不变 |
| 标签隔离 | 修改/打乱标签 | 未依赖标签的原始因子不变 |
| 手算小例子 | 价格序列、缺口、零量、平盘、股票交界 | 与每个公式及缺失规则一致 |
| 分区接续 | 连续计算与分年/分批计算比较 | 分区边界因子及缺失掩码一致 |
| 训练截止 | 设置跨界标签 | 未成熟标签不能进入 scaler/监督训练集合 |
| scaler 隔离 | 首次 fit 时改 valid/test；合并重训时只改该窗口 test | 所检查 fit 阶段的 scaler 不变；固定配置的模型训练不依赖该阶段以后的样本。valid 选型后参数变化不属于首次 fit 不变性检查 |
| 状态冻结 | 同一个 test 块的多日预测前后比较状态摘要 | scaler 和模型参数不变；因子历史缓存允许推进，下一窗口允许重新拟合 |
| 窗口拼接 | 检查相邻 test 块和已保存预测 | 日期连续、键不重复，后续重训不覆盖旧窗口预测 |
| 预测未来扰动 | 改变 T 后输入 | 已保存且固定状态下 T 及以前预测不变 |
| 同日横截面例外 | 改同日其他股票数据 | 若启用截面因子，允许同日预测变化；不能要求股票完全隔离 |
| 键与评分 | 全键对齐、原标签核查、对照官方脚本 | 没有漏键/重复键，评分在数值容差内一致 |
| 资源 | 真因子完整窗口实测 | 记录峰值内存、耗时、线程和版本，无内存溢出 |

因子 float32 比较默认 `atol=1e-7, rtol=1e-6`，先分别比较缺失掩码；因子尺度特殊时在该因子 spec 明确调整。评分与官方脚本对照默认绝对容差 `1e-12`。

注意：不能要求改变同次训练期后半段后，该次 scaler 变换的训练期前半段仍不变；整个拟合区间参与统计量估计是本稿的窗口内固定 scaler 定义。未来扰动测试应分别针对原始因子的逐日信息边界、以及每次拟合的截止边界；不能把前一个 test 后来进入新的训练窗误判为泄漏。

## 13. 实验记录与修改流程

每次正式实验记录：实验 ID、窗口 ID、滚动/固定/在线模式、数据/因子/spec 版本、代码版本、股票与样本范围、train/valid/test 边界、两个拟合阶段的截止与 scaler 状态、模型参数和随机种子、原始 OOS 预测及覆盖率、官方分项、耗时与峰值内存。正式比较引用不可变输入快照，不覆盖旧结果。

用户先修改本稿和因子稿；确认后同步旧计划的时间协议，生成机器配置与因子 catalog，再补充程序约束和验收。没有正式因子清单时，不能把烟测模拟列当研究特征。

当前实现差距：已有按窗读取、标签成熟掩码、Qlib 烟测、预测补齐和评分适配器；尚需滚动窗口生成与拼接、scaler 两阶段 fit/transform 生命周期、因子因果检查、合格模型预测的 NaN/Inf 报错、Top 候选覆盖检查，以及上述完整实验记录。此稿仅明确这些需求，不宣称现有代码已全部满足。
