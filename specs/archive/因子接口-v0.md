# 因子接口 v0（已归档）

> 该文档记录早期接口约定，路径和实现已过时，不作为当前开发依据。当前实现请看 [因子 spec](../因子spec草案.md)、[README](../../README.md) 和 `scripts/qlib_bridge.py`。归档用于保留决策历史。

当前已生成 `data/prepared/train_YYYY.parquet` 与 `test_YYYY.parquet`，保留了所有原始行和数值，增加 `source_row`、`bar_valid`、`volume_zero`、`label_present`、`label_maturity_date`、`valid_bar_run`。各列含义和原始文件校验值见 `data/prepared/manifest.json`。所有逻辑表主键为 `(trade_date, ts_code)`。

因子使用 `scripts/build_factors.py` 从处理后的日线生成：每个年度写入 `data/features/features_YYYY.parquet`，列为两个主键及按 catalog 固定顺序排列的 8 个候选 `feature_*`。计算跨年度时读取上一年数据作为历史暖启动，只输出本年度源键；2018 年之前没有题给数据，较长窗口按缺失处理。该程序不读取标签，年表保留源数据全部键。公式和版本写入 `data/features/catalog.json`。

fixed 统一入口为 `scripts/run_fixed_baseline.py --phase D|H|S`。D 对照 1 日收益延续/反转参照信号、Ridge 与 LightGBM，并允许四种输入变换；按标签成熟截止修正后，H/S 锁定 D 预选的 LightGBM + 原值输入，不接受候选模型或变换覆盖。阶段边界定义在脚本及《QR基础设施交接说明.md》。H 只报告 2024 历史评分，不据此调参；S 对 2025—2026 生成 `submission.csv`，禁止使用测试标签评分。脚本复用 `scripts/qlib_bridge.py` 的窗口读取、成熟标签掩码及 Qlib `StaticDataLoader`／`DatasetH` Ridge 接口；不运行 rolling/adaptive。

```bash
.venv/bin/python scripts/build_factors.py
.venv/bin/python scripts/run_fixed_baseline.py --phase D --models ridge lightgbm --transforms train_zscore cs_zscore cs_rank identity
.venv/bin/python scripts/run_fixed_baseline.py --phase H
.venv/bin/python scripts/run_fixed_baseline.py --phase S
.venv/bin/python scripts/validate_pipeline.py
```

完整 D 候选运行：

```bash
.venv/bin/python scripts/run_fixed_baseline.py \
  --phase D --models ret1_momentum ret1_reversal ridge lightgbm \
  --transforms train_zscore cs_zscore cs_rank identity
```

所有输出位于被 Git 忽略的 `outputs/fixed_baseline/`；D 输出写在根目录并按方案键合并，H/S 分别写入 `H/` 和 `S/` 子目录。D 分数用于开发选型，不作为独立检验。

| 表 | 必需列 | 用途 |
|---|---|---|
| `features` | `trade_date`, `ts_code`, `feature_*` | 仅包含截至该日可得信息的候选因子 |
| `labels` | `trade_date`, `ts_code`, `y_ret_1d` | 原始官方标签；保留 NaN |
| `auxiliary` | `trade_date`, `ts_code`, `flag_limit_up`, `flag_limit_down`, `bar_valid`, `valid_bar_run` | 训练、预测、评分的辅助掩码 |
| `feature_catalog` | 特征名、公式、窗口、输入字段、最早可用日、缺失规则 | 因子定义和时间口径 |

## 不变量

1. 每张表的主键唯一，日期和股票代码不作隐式重排。
2. `feature_*` 在日期 `t` 只使用该股票和当日横截面截至 `t` 的数据。
3. 训练窗口内拟合的标准化、填补、PCA、标签筛选参数不能提前写入 `features`。
4. `y_ret_1d` 不截断、不标准化、不由审计脚本替换。模型若需要转换标签，转换仅在训练期完成并记录。
5. 测试集的每一行都有 `features` 和 `auxiliary` 记录；即使行情缺失，也不丢失提交键。
6. 先不定义 `close / (amount / vol)` 类特征，因为给定后复权价格与成交均价未证明具有相同复权尺度。
7. 标签有其成熟时点：日期 `t` 的 `y_ret_1d` 只能在下一条可用日线收盘后进入训练。训练集末端有 4,525 个标签由测试集首个收盘价验证；它们可用于离线全训练，但不能在其收益尚未实现时提前进入滚动训练窗口。

## 缺失处理规则 v0

审计证据显示：训练集的 1,139,980 条完整行情缺失行全部同时缺少标签；另有 1,839 条“行情完整、标签缺失”的行。以下规则作为首版因子和模型的默认口径。

| 情况 | 原始数据与因子 | 训练 | 测试提交 |
|---|---|---|---|
| 当日 OHLCV/amount 完整，标签完整 | 正常计算候选因子 | 可进入训练，前提是满足所选特征的历史窗口要求 | 正常模型预测 |
| 当日行情完整，标签缺失 | 正常计算候选因子，保留 `label_available=0` | 不进入监督损失 | 正常模型预测；测试期标签不可见不影响提交 |
| 当前日任一 OHLCV/amount 缺失 | 不填充原始价格、成交量或成交额；设置 `bar_valid=0`，依赖这些字段的因子置为缺失 | 不进入首版训练 | 保留完整提交键，设置保守预测值 |
| 当前日成交量为 0、但其他字段存在 | 不视为行情缺失；设置 `volume_zero=1`；价格类因子可算，需除以成交量的因子置缺失 | 按模型的特征可用规则决定；Ridge 的填补参数仅在训练窗口拟合 | 同常规模型预测，保留标记 |
| 历史窗口中存在无效日线 | 不前向填充，不把缺口两端视作连续日线；要求窗口内有效观测完整，相关滚动因子置缺失 | 不因该行本身的标签有效就强制入样 | 若无法得到完整特征，使用保守预测值 |

### 标记与掩码

- `bar_valid`：当前日 OHLCV/amount 全部非缺失。
- `label_available`：训练集中 `y_ret_1d` 非缺失，且在滚动模拟中已经成熟。
- `history_ready_L`：当前因子集合所需的最长回看窗口 `L` 内，所需日线均有效。
- `model_ready`：`bar_valid=1` 且 `history_ready_L=1`。首版监督训练再加 `label_available=1`。
- `volume_zero`：成交量为零但数据并不缺失，避免在量能比率中将 0 误当作缺失或以极小常数制造极端值。

处理后数据已物化 `valid_bar_run`，`history_ready_L` 由正式因子集合的窗口长度 `L` 决定。`label_present` 仅表示题给标签非缺失；滚动训练还需判断 `label_maturity_date` 是否已经到达该次拟合时点。测试集的 `y_ret_1d` 与 `label_maturity_date` 分别为缺失和 0，它们不代表真实未来收益为零。

接入函数要求显式传入由正式因子清单确定的 `min_valid_run`，再从 `valid_bar_run` 生成 `history_ready_L`。它还要求训练调用传入 `label_asof_date`。返回的 `labels` 始终是题给原值；只有构建 Qlib 训练数据时，才将不满足 `label_available & model_ready` 的标签临时置缺失，让监督模型排除这些行。评分应使用原始 `labels`，不能使用训练掩码后的标签。`model_ready` 同时要求全部已选因子非缺失；如果后续模型允许部分因子缺失，需要先明确修改这一版完整样本口径并重新验证。

### 保守预测值

测试集必须为每个 `(trade_date, ts_code)` 输出一行 `pred`。对 `model_ready=0` 的行：

1. 仍保留所有因子缺失标记，便于审计和后续敏感性分析。
2. 当日有效、可模型预测股票先得到 `pred_model`。
3. 对无效行设 `pred = min(pred_model) - max(max(pred_model)-min(pred_model), 1e-6)`；它严格低于当日所有正常预测，因而不会因并列排序进入 Top 10% 候选池。
4. 若某日没有任何有效模型预测，停止生成提交文件并报错，而非用全截面常数掩盖问题。

该保守值不代表对未来收益的经济判断，只是把没有足够输入信息的股票排出模型候选池。它需要在模型生成正常预测之后按日计算，因此当前处理后数据没有 `pred` 列。它将在训练集模拟中与其他回填方案比较，但首版固定采用本规则，避免因缺失行和并列排序污染官方 Jaccard 换手指标。
